💡 O que é o Intelligent Career Planner?

Este projeto nasceu da necessidade de organizar informações relacionadas ao desenvolvimento profissional, centralizando estudos, projetos, certificações e metas em um único lugar.

A proposta é disponibilizar uma base que possa ser utilizada e adaptada por qualquer profissional de tecnologia.

Customize com seus próprios dados editando data/resume.json e usando o painel admin para adicionar tarefas, projetos, competências e certificados.

✔ Funcionalidades
  • Plano de estudos com área, prioridade, prazo e horas estimadas
  • Revisão semanal (Weekly Review) com log diário
  • Gestão de projetos pessoais e corporativos com progresso e evidências
  • Dashboard de competências técnicas por categoria
  • Gerenciador de certificados com emissor, data e credencial
  • Gerador de currículo (HTML + PDF) baseado nos dados do banco
  • Modo admin protegido + modo visualização (recrutador)
  • Backup e restauração de dados em JSON

🚀 Primeiros passos
  • Clone o repositório e rode pip install -r requirements.txt
  • Execute python app.py — o banco é criado automaticamente com dados demo
  • Acesse /admin?key=admin2026 para ativar o modo edição
  • Edite data/resume.json com seus dados pessoais
  • Adicione seus próprios projetos, certificados e competências pelo admin
